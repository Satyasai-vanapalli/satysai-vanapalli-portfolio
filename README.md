# Satya Sai Portfolio

Personal portfolio built with Next.js 16, React 19, and TypeScript. It includes project links, skills, achievements, coding profiles, and a downloadable resume.

## Run locally

```bash
npm install
npm run dev
```

open https://satyasai-vanapalli.github.io/satysai-vanapalli-portfolio/

## Build

```bash
npm run build
npm run start
```

The coding profile cards fetch live data from the platforms where public statistics are available. The combined solved count uses the live counts from LeetCode, Codeforces, and CodeChef.
